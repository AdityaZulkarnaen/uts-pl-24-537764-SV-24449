# Backend — Inventaris Lab API

RESTful API Laravel 13 dengan autentikasi token Laravel Sanctum.

- Kode utama: `app/Http/Controllers/Api`, `app/Http/Requests`, `app/Http/Resources`, `routes/api.php`
- Test: `tests/Feature` (`php artisan test`)
- Docker: `Dockerfile` (FrankenPHP), `docker/Caddyfile`, `docker/entrypoint.sh`

Petunjuk menjalankan ada di README pada akar repository.
